# Stickfigure Platformer Game

A standalone platformer game built with Next.js and Canvas API.

## Quick Start

```bash
npm install
npm run dev
```

Visit http://localhost:3001

## Build for Production

```bash
npm run build
npm start
```

## Deploy

This is a standard Next.js app that can be deployed to:
- Vercel (easiest: `vercel`)
- Netlify
- Any Node.js hosting
- Static export: Add `output: 'export'` to next.config.mjs

## Game Controls

- **Arrow Keys / WASD**: Move
- **Space**: Jump
- **Mouse Click**: Shoot
- **Number Keys 1-9**: Switch weapons
- **ESC**: Pause menu

Survive waves of enemies and see how long you can last!
